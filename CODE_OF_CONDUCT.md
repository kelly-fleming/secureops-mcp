# Code of Conduct

This is a personal hobby project. Please keep issues, pull requests, and other
project discussions respectful and constructive. Questions and good-faith
corrections are welcome, whatever your experience level.

Personal attacks, harassment, discriminatory remarks, threats, sexualized
attention, intimidation, and publishing someone else's private information are
unacceptable. Do not pressure anyone to disclose credentials or sensitive data.

## Reporting concerns

Email me at [kelly89.fleming@gmail.com](mailto:kelly89.fleming@gmail.com) to report
conduct concerns confidentially. Include relevant links and a brief description.

For conduct on GitHub, use [GitHub's abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
If GitHub offers **Report to repository admins** on the affected content, you can
also use that option to notify the maintainer. Avoid putting sensitive personal
details in a public issue. Security vulnerabilities have a separate reporting
process in [SECURITY.md](SECURITY.md).

I may remove content or limit participation to keep project discussions safe and
useful. Retaliation against someone reporting a concern is unacceptable. This
policy applies to project-maintained spaces and participation in this project.
